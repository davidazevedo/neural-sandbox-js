# Conceitos Envolvidos

## Perceptron
Modelo de classificador linear criado por Frank Rosenblatt.

## Funções de Ativação
- **ReLU**: Retorna 0 se entrada < 0; caso contrário retorna a entrada.
- **Sigmoid**: Compressão suave dos valores entre 0 e 1.
