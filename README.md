# Neural Sandbox JS

Um simulador interativo de redes neurais, desenvolvido para auxiliar no entendimento de conceitos fundamentais de Machine Learning e Redes Neurais Artificiais.

## 🎯 Sobre o Projeto

Este projeto é parte da pesquisa de mestrado em Inteligência Artificial e Educação, desenvolvida pelo autor. O simulador permite visualizar o processo de aprendizado de uma rede neural simples, com foco especial em funções de ativação e seus impactos no processo de classificação.

## 🚀 Funcionalidades

- Visualização interativa do processo de aprendizado
- Suporte a múltiplas funções de ativação (ReLU e Sigmoid)
- Controle da taxa de aprendizado
- Visualização da fronteira de decisão em tempo real
- Interface intuitiva com tooltips explicativos
- Sistema de logs para acompanhamento do treinamento
- Modal de ajuda com explicações detalhadas
- Design responsivo e moderno

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (com variáveis CSS e Flexbox/Grid)
- JavaScript (ES6+)
- Canvas API
- Font Awesome (ícones)

## 📚 Como Usar

1. Clone o repositório
2. Abra o arquivo `public/index.html` em seu navegador
3. Interaja com o canvas clicando para adicionar pontos
4. Use os controles para:
   - Selecionar a função de ativação
   - Ajustar a taxa de aprendizado
   - Definir o número de épocas
   - Treinar a rede neural
   - Limpar ou resetar o estado
5. Observe como a fronteira de decisão se ajusta durante o treinamento
6. Consulte o modal de ajuda para entender melhor os conceitos
