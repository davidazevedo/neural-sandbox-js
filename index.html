 Conceitos

                    

                        
 Perceptron

                        
Unidade básica de uma rede neural que recebe entradas, aplica pesos e uma função de ativação.

                    

                    

                        
 Função de Ativação

                        
Transforma a entrada linear em uma saída não-linear, permitindo que a rede aprenda padrões complexos.

                    

                    

                        
 Backpropagation

                        
Algoritmo que ajusta os pesos da rede neural para minimizar o erro de previsão.

                    

                

            

        

    


    
    

        

            

                
 Ajuda

                
            

            

                

                    
 Explicação da Tela

                    
Esta interface permite simular o comportamento de uma rede neural simples com duas funções de ativação: ReLU e Sigmoid. Você pode adicionar pontos ao plano cartesiano, escolher a função de ativação, controlar a taxa de aprendizado e visualizar a separação das classes.

                

                

                    
 Explicação das Funções

                    

                        
ReLU (Rectified Linear Unit)

                        
Retorna 0 para valores negativos e o valor original para positivos. Simples e eficiente, comum em redes profundas.

                    

                    

                        
Sigmoid

                        
Compressão suave dos valores entre 0 e 1. Ideal para saídas probabilísticas e tarefas binárias.
